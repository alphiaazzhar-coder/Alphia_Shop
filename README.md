# Alphia Shop — Stage 1

A responsive, beginner-friendly fashion shopping homepage built with HTML, CSS, and JavaScript.

## Run it

1. Open the `alphia-shop` folder in your code editor.
2. Double-click `index.html` to open it in a browser, or use a Live Server extension for automatic refreshes while you edit.
3. Edit product names, categories, prices, and image URLs in `script.js`. Change colours and page styling in `style.css`.

## Included

- Professional header, navigation, hero, categories, product sections, newsletter, and footer
- Responsive mobile layout
- Add-to-bag counter and wishlist counter
- Product data rendered from JavaScript
- Search feedback and newsletter confirmation

This is a frontend-only Stage 1. The cart and newsletter demonstrate interactions in the browser; they do not save data yet.
